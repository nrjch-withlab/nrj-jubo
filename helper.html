Netlify에 파일 올리기 (드래그&드롭)
다운로드한 jubo.json 파일을 Netlify에 끌어다 놓기만 하면 완료

📂 Netlify 업로드 방법

  1. app.netlify.com 접속 → 로그인
    북마크에 저장해두세요
  2. 노량진교회 주보 사이트 클릭
  3. 상단 메뉴 Deploys 클릭
  4. 페이지 아래쪽 Drop to upload 영역에
    다운로드한 jubo.json 파일을 끌어다 놓기
  5. 자동으로 배포 시작 → 1~2분 후 완료 ✅
💡 파일이 하나뿐이어도 됩니다. jubo.json만 교체해도 전체 주보가 바뀝니다. index.html 등 다른 파일은 건드리지 않아도 됩니다.

첨부한 PDF는 노량진교회 주일예배순서 주보입니다.
PDF의 모든 내용을 빠짐없이 읽어서 아래 JSON 형식에 맞게 변환해 주세요.

규칙:
1. 내용을 절대 요약하거나 생략하지 마세요. PDF에 있는 그대로 옮기세요.
2. 큰따옴표(")가 값 안에 들어갈 때는 앞에 역슬래시를 붙여주세요: \"이렇게\"
3. 줄바꿈이 필요한 곳은 \n을 사용하세요.
4. JSON 형식을 정확히 지켜주세요. 중괄호, 대괄호, 쉼표 누락 없이.
5. church_life의 tag는 아래 중 하나로 지정하세요:
   - 오늘 / 예고 / 안내 / 정기 / 특별 / 선교부 / 동산 / 청년1부 / 청년2부 / 기타
6. 헌금 명단(십일조, 범사의감사 등)은 이름을 공백으로 구분해서 하나의 문자열로 넣으세요.
7. 셔틀버스 노선은 → 대신 →를 그대로 사용하세요.
8. 오후예배 순서는 order 배열에 순서대로 넣으세요.
9. 심방 담당 권사는 intercession에, 예배 안내는 worship_guide에 넣으세요.
